# LumiPet model folder

LumiPet does not ship with a character model. On first launch, choose a folder containing one or more Live2D Cubism 3 or 4 `.model3.json` files and their referenced resources.

Models may be stored directly in this folder or in subfolders. Use the right-click menu to switch between valid models or choose another folder. Resource references must stay inside the selected folder.
